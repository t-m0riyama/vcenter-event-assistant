# インシデント

<!-- vea-tab-help: incidents -->

「インシデント」タブでは、障害の状態・担当・経過と、関係するイベント・通知・スナップショットをまとめて記録できます。

## 一覧と詳細

- 一覧の既定は **未解決**（対応中・様子見）です。状態を切り替えるか、件名を入力して **検索** を押すと絞り込めます。最終更新が新しい順に表示します。
- 件名を押すと詳細を開きます。詳細の URL（`#/incidents/<id>`）は、同じ環境の閲覧権限を持つ利用者と共有できます。
- **インシデントを作る** で件名を入力します。詳細の **編集** で状態・重大度・担当・開始時刻と、原因や対応の要約を記録できます。認証が有効な環境では、担当の **自分** でログイン中の名前を入力できます。
- **経過** にメモを追加できます。項目や紐付けの変更も記録され、古い順に並びます。削除された行には、削除した人が表示されます。
- 保存時に「ほかの人が更新しました。読み直してください」と出た場合は、**読み直す** を押し、入力した内容と最新の内容を見比べてから保存してください。

閲覧は viewer 以上、作成・編集・紐付け・メモの追加は operator 以上です。経過の本文とインシデント全体の削除は admin が行えます。

## 調査中の画面から追加する

**インシデントに追加** を押し、未解決のインシデントを選ぶか、**新しく作る** を選びます。追加後は、追加できた件数や、元の行が見つからなかった件数などを確認できます。

- [イベント](events.md) の行からイベントを追加できます。
- [通知履歴](alerts.md) の行から通知を追加できます。行の **インシデントを作る** を押すと、ルール名と対象を件名の下書きに使います。
- [タイムライン](timeline.md) のイベントとアラートの行、構成変更と障害パターンのカード、結果ありのスナップショットを追加できます。まとめた行からは先頭の 1 件、カードからは最大 20 件のイベントを追加します。

## 紐付けた記録を見る

イベント・通知は、追加した時点の要点を写します。元の行が残っていれば **前後 30 分のタイムライン** を開けます。保持期間などで元の行が削除された後も、写しは詳細で読めます。紐付けを **外す** と写しも削除されます。

スナップショットは **タイムラインで開く** で保存した結果を表示し、**調査資料を出力** から Markdown または ZIP を取得できます。紐付けを外すと、行と保存結果は次の保持期間の削除から通常の設定に従います。

## 保持期間と閲覧範囲

未解決のインシデントは保持され、解決から既定 90 日で削除されます。解決後のメモや紐付けで期間は延びません。保持期間を無効にする設定と、紐付け中のスナップショットの扱いは、運用ガイドに記載しています。[バックエンド運用ガイド](../operations/backend-operations.md)

メモや写しに含まれる利用者名などの情報は、viewer 以上が閲覧できます。チャットには渡りません。インシデント記録に署名や改ざんの検知はありません。
